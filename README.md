# rising-from-darkness

Одноэкранный цифровой портрет. Canvas считывает пиксели исходной фотографии и строит из цветных моноширинных символов ту же композицию. Символы поднимаются снизу, постепенно собираясь в портрет. За вступлением следуют едва заметное дыхание и печать цитаты.

## Локальный запуск

В каталоге проекта запустите сервер с помощью Python 3.

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Откройте страницу в браузере. [Локальный сайт](http://127.0.0.1:8765/)

Перезагрузка страницы повторяет вступление. При включённой системной настройке уменьшения движения сразу видны собранный портрет и полная цитата.

## Файлы

- `index.html` — разметка и текст цитаты.
- `style.css` — композиция, адаптивная типографика и курсор.
- `script.js` — анализ пикселей, отрисовка символов и анимация.
- `assets/reference.png` — исходная фотография.
- `.nojekyll` — отключение обработки Jekyll на GitHub Pages.
- `.gitignore` — исключения для локальных служебных файлов.

## GitHub Pages

Для будущей публикации загрузите файлы в репозиторий и выберите корень нужной ветки в настройках GitHub Pages. Пути к ресурсам относительные. Сборка и установка зависимостей не требуются.
